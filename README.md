# Portfólio Acadêmico — Ciência da Computação (UNICID)

Repositório consolidado das atividades e unidades práticas desenvolvidas ao longo da disciplina acadêmica.

## 📁 Estrutura do Repositório

| Unidade | Descrição / Tecnologias |
| :--- | :--- |
| **Unidade 1** | Introdução ao desenvolvimento Web, Java, JSP e configuração de ambiente. |
| **Unidade 2** | Aplicação de bibliotecas de tags (JSTL) para manipulação de dados em páginas JSP. |
| **Unidade 3** | Arquitetura Java Web com Servlets, mapeamento de requisições e respostas HTTP. |
| **Unidade 4** | Integração com banco de dados MySQL utilizando DAO (*Data Access Object*) e JDBC. |
| **Unidade 5** | Desenvolvimento com **Spring MVC**, injeção de dependências e controladores Web. |
| **Unidade 6** | Mapeamento Objeto-Relacional (ORM) e operações CRUD avançadas com **Hibernate** e JPA. |

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java (JDK 8+)
* **Frameworks & Libs:** Spring MVC, Hibernate ORM, JSTL
* **Banco de Dados:** MySQL / MySQL Connector
* **Servidor de Aplicação:** Apache Tomcat
* **IDE & Ferramentas:** Eclipse IDE, Git, GitHub, CMD Windows
